## Overview
This wedding invitation website combines modern design with functionality to create a memorable online presence for wedding celebrations. It features smooth animations, responsive design, and an intuitive user interface that works seamlessly across all devices.

## Requirements

### Minimum System Requirements
- PHP 7.4+ with the following extensions:
  - mysqli
  - json
  - gd
  - mbstring
- MySQL 5.7+ or MariaDB 10.2+
- Apache 2.4+ or Nginx 1.16+
- Modern web browser (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)
- 512MB RAM minimum (1GB recommended)
- 100MB disk space (excluding media files)

### Recommended Server Configuration
- Enable PHP short_open_tag
- Set max_execution_time = 300
- Set upload_max_filesize = 10M
- Set post_max_size = 10M

## Quick Start

### Static Website (GitHub Pages Version)
1. View the live demo at https://shin-da.github.io/wedding-invitation
2. Or clone and run locally:
```bash
git clone https://github.com/Shin-da/wedding-invitation.git
cd wedding-invitation
```
Then open `index.html` in your web browser.

### Full Version with RSVP System
1. Clone the repository
2. Set up your local server (XAMPP/WAMP/LAMP)
3. Import the database:
   ```sql
   mysql -u root -p wedding < database/wedding.sql
   ```
4. Configure database connection in `config/database.php`
5. Access through your local server (e.g., http://localhost/wedding-invitation)

### Customization
- Update wedding details in `index.html`
- Modify styles in `css/main.css`
- Adjust animations in `js/main.js`
- Configure RSVP system in PHP files
- Replace images in `assets/images/`

## Troubleshooting

Common issues and solutions:

### RSVP System
- **Database Connection Failed**: Check config/database.php credentials
- **Form Not Submitting**: Verify PHP extensions are enabled
- **Images Not Uploading**: Check folder permissions and PHP limits

### Display Issues
- **Animations Not Working**: Ensure JavaScript is enabled
- **Maps Not Loading**: Check Google Maps API key
- **Gallery Not Opening**: Verify LightGallery.js installation

## Customization Guide

### Basic Customization
1. **Wedding Details**
   - Edit `index.html` for main content
   - Update dates in `js/main.js`
   - Modify venue details in `pages/details.html`

2. **Visual Changes**
   - Colors: Edit CSS variables in `css/main.css`
   - Fonts: Update Google Fonts in header
   - Images: Replace files in `assets/images/`

3. **RSVP System**
   - Modify form fields in `pages/rsvp.php`
   - Update email templates in `includes/utils.php`
   - Adjust database schema if needed

### Advanced Customization
- Custom animations: Edit AOS configurations
- Add new features: Extend PHP classes
- Modify database structure: Update schemas
